# Audit 7.23

53 pages de paramètres parcourues ; 188 lignes avec information, plus les champs isolés. Aucun groupe vide ni erreur JavaScript observés dans ces scénarios. Les 39 options de décor ont un exemple calculé par le moteur actuel, avec des données fictives et sans modifier les préférences.

Doublon d’interface supprimé : la seconde barre d’onglets dans les paramètres ; les mêmes rubriques restent dans la colonne de gauche et la recherche. Aucune préférence ni fonction utilisateur supprimée. Les modules historiques chargés par index.html restent des couches actives de l’application, ils ne sont pas supprimés en fonction de leur ancien numéro de version.

Tous les scripts applicatifs vérifiés en syntaxe, fichiers JSON et Python analysés, cinq sources Java compilées ensemble. Le script Windows est actualisé pour compiler les cinq modules et demander le mot de passe par variable d’environnement. Les bibliothèques et leurs licences sont conservées.

Les tests de reconnaissance utilisent des routes contrôlées : autoroute à l’arrêt, rue parallèle, carrefour, changement de cap, sens unique opposé, GPS ancien/imprécis, absence de réseau et callback manquant. Ils ne prouvent pas une reconnaissance parfaite des routes réelles.

GPS : tests de changement de section, retour, absence d’ouverture initiale, arrière-plan et refus du système ; compilation du pont Android et contrôle de la permission normale REORDER_TASKS. Aucun test physique des tâches de l’autoradio.
